# Employee Attendance Management System

A Flask + MySQL/MariaDB web application for managing employee attendance.

## Current status

- **Phase 1:** Development environment (Python, Git, XAMPP/MariaDB) - complete
- **Phase 2:** Project foundation - complete

## Setup

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env   # then edit values
python run.py
```

Open http://127.0.0.1:5000/ and http://127.0.0.1:5000/health.

## Technology

Python 3.12, Flask 3, PyMySQL, MariaDB 10.4 (MySQL-compatible), Bootstrap 5.
